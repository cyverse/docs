# Terrain endpoints

Endpoint documentation by resource. The generated Swagger reference at
[de.cyverse.org/terrain/docs](https://de.cyverse.org/terrain/docs){target=_blank}
is the most current source; these documents cover endpoints that are not yet in it,
and add detail where the generated reference is thin.

* [Endpoints overview](https://docs.cyverse.org/api/endpoints/endpoints/) - how this documentation is organized

# Apps and analyses

* [App metadata](https://docs.cyverse.org/api/endpoints/app-metadata/) - metadata attached to apps
* [App ontologies](https://docs.cyverse.org/api/endpoints/app-ontologies/) - ontology hierarchies used to classify apps
* [Quick launches](https://docs.cyverse.org/api/endpoints/quick-launches/) - saved launch configurations and their sharing
* [Callbacks](https://docs.cyverse.org/api/endpoints/callbacks/) - status reported back to the DE by other services
* [Terrain and apps services](https://docs.cyverse.org/api/endpoints/terrain-v-apps/) - how responsibilities are split

# Data

* [File I/O](https://docs.cyverse.org/api/endpoints/fileio/) - upload, download, and streaming
* [filesystem/](https://docs.cyverse.org/api/endpoints/filesystem) - listings, metadata, permissions, sharing, and trash

# Users

* [Notifications](https://docs.cyverse.org/api/endpoints/notifications/) - user notifications and system messages
* [Comments](https://docs.cyverse.org/api/endpoints/comments/) - comments on data and apps
* [Favorites](https://docs.cyverse.org/api/endpoints/favorites/) - favorite data items and apps

# Publishing

* [Permanent ID requests](https://docs.cyverse.org/api/endpoints/permanent-id-requests/) - the DOI and ARK request workflow
