# Products and services

The user-facing layer of CyVerse. These documents describe what each service *is*;
building them is covered in [deployment/](https://docs.cyverse.org/deployment).

<figure markdown>
  ![layercake](https://docs.cyverse.org/assets/layerCake.svg){width=800}
  <figcaption>The CyVerse layer cake: hardware, then services, then products</figcaption>
</figure>

# Data

* [Data Store](https://docs.cyverse.org/platform/data-store/) - iRODS storage with WebDAV, SFTP, and API access
* [Data Commons](https://docs.cyverse.org/platform/data-commons/) - publishing curated and community-released datasets

# Compute

* [Discovery Environment](https://docs.cyverse.org/platform/discovery-environment/) - the web-based data science workbench
* [Cloud services](https://docs.cyverse.org/platform/cloud/) - CACAO infrastructure-as-code for multi-cloud deployments

# Specialized applications

* [BisQue](https://docs.cyverse.org/platform/bisque/) - bio-image semantic query and analysis
* [DNA Subway](https://docs.cyverse.org/platform/dna-subway/) - educational genomics workflows

# Platform services

* [Authentication](https://docs.cyverse.org/platform/authentication/) - Keycloak, CILogon, and OAuth 2.0
* [Subscriptions](https://docs.cyverse.org/platform/subscriptions/) - resource allocations and how they are managed
* [Terrain API](https://docs.cyverse.org/api/terrain/) - the API every product is built on
